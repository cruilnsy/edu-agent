QA agent graph

Ten nodes and three conditional routes. Every question enters at classify_query, is routed by question type and retrieval confidence, and ends at save_memory. The graph is compiled with a MemorySaver, so each thread_id keeps its conversation.

The three routes

1. By question type

classify_query → _route_by_query_type
ConditionGoes to
GENERAL, web offgenerate_general
GENERAL, web onweb_search
PRECISEretrieve
VAGUEhyde_generate
BROADmulti_query_rewrite

2. By retrieval confidence

retrieve → _route_by_confidence
ConditionGoes to
Top rerank score ≥ 0.75generate_rag
< 0.75, web onweb_search
< 0.75, web offgenerate_direct

3. After web search

web_search → _route_after_web_search
ConditionGoes to
query_type = GENERALgenerate_general
Otherwise (low confidence)generate_direct

Nodes

classify_query
Rules plus the fine-tuned classifier decide GENERAL / PRECISE / VAGUE / BROAD, and detect requests to search the web.
hyde_generate
For a vague question, the LLM writes a hypothetical answer, which is used for retrieval instead of the question.
multi_query_rewrite
A broad question is split into sub-queries, retrieved in parallel, then merged without duplicates.
retrieve
BGE-M3 dense + sparse hybrid recall, then the BGE reranker keeps the top 3. The top score is the confidence.
generate_rag
Answers only from the retrieved knowledge base content and lists the sources.
web_search
Calls the web search MCP server (Tavily first, DuckDuckGo as fallback). If the service is down it returns nothing and the flow continues.
generate_direct
The LLM answers when the knowledge base is not enough, using search results if there are any; otherwise it adds a note.
generate_general
Greetings and questions unrelated to the courses; uses search results when the web is on.
enqueue_pending
Adds the low-confidence question to knowledge_pending_queue so a teacher can fill the gap; duplicates are ignored.
save_memory
Saves this turn. Every path ends here.

Only answers from generate_direct go to the gap queue: questions the knowledge base could not answer well are recorded, while GENERAL questions and high-confidence answers are not.
